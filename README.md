# ResNet-18 against a vision transformer on CIFAR-10

MSc coursework, Deep Learning for Vision and NLP, University of Stirling.

Compares a convolutional network (ResNet-18) with a vision transformer on the CIFAR-10 image classification dataset, loaded through PyTorch.

## Results

| Model | [Metric, for example test accuracy] |
| --- | --- |
| ResNet-18 | [78.51%] |
| Vision transformer | [38.80%] |

Training curves for both models are in the .ipynb file.
